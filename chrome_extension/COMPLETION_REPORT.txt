STORAGE SCHEMA
================================================================================

chrome.storage.local:

  resumePdfData (String)
  - Base64-encoded PDF file
  - Max size: ~13.3MB (10MB PDF limit)
  - Purpose: Store actual PDF content

  resumePdfMetadata (Object)
  - Fields: filename, size, uploadedAt
  - Size: ~200 bytes
  - Purpose: Track PDF information

USER WORKFLOW
================================================================================

Step 1: Upload Resume
  1. Open extension popup
  2. Scroll to "Resume PDF Upload" section
  3. Click file input field
  4. Select your resume PDF
  5. Wait for validation (1-2 seconds)
  6. See "✓ PDF Ready" with filename and date

Step 2: Auto-Attach on Job Forms
  1. Navigate to job application form
  2. Content script automatically detects resume fields
  3. Adds "📄 Attach PDF" button near resume input
  4. Click the button
  5. PDF is automatically attached
  6. See success toast: "✓ Resume PDF attached: filename.pdf"
  7. Complete rest of application
  8. Submit form with PDF included

Step 3: Remove PDF (Optional)
  1. Open extension popup
  2. Go to Resume PDF section
  3. Click "Remove PDF" button
  4. Confirm removal
  5. Status changes to "No PDF"
