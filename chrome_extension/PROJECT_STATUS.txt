INSTALLATION INSTRUCTIONS
================================================================================

For Chrome (Development/Testing):
  1. Go to chrome://extensions/
  2. Enable "Developer mode"
  3. Click "Load unpacked"
  4. Select the chrome_extension directory
  5. Extension should appear in extension list

For Firefox:
  1. Go to about:debugging#/runtime/this-firefox
  2. Click "Load Temporary Add-on"
  3. Select manifest.json file
  4. Extension should appear

Configuration:
  1. Click extension icon in toolbar
  2. Paste resume text in popup
  3. Configure preferences (salary, notice, visa)
  4. Add portfolio/GitHub/LinkedIn URLs (optional)
  5. Add Gemini API key if not set
  6. Save settings

Usage:
  1. Navigate to job application form
  2. Extension auto-detects form fields
  3. Resume fields auto-fill instantly
  4. Preference fields populate automatically
  5. URLs and PDFs attach to file fields
  6. Gemini answers behavioral questions
