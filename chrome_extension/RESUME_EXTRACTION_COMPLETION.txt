EXTRACTION PATTERNS
================================================================================

Email Detection:
  Regex: [a-zA-Z0-9._-]+@[a-zA-Z0-9._-]+\.[a-zA-Z0-9_-]+
  Example: john.smith@example.com ✓

Phone Detection:
  Regex: (\+?1?\s?)?(\([0-9]{3}\)|[0-9]{3})[\s.-]?[0-9]{3}[\s.-]?[0-9]{4}
  Formats:
    - (555)123-4567  ✓
    - 555-123-4567   ✓
    - 555.123.4567   ✓
    - +1-555-123-4567 ✓

Name Detection:
  Pattern: First capitalized line with capitalized words
  Example: "John Smith" ✓

Location Detection:
  Keywords: Location:, City:, Based in
  Example: "Location: San Francisco, CA" ✓

Job Title Detection:
  Pattern: Capitalized line with role keywords
  Keywords: Engineer, Developer, Manager, Lead, Architect, Designer, Director, Analyst, Specialist
  Example: "Senior Software Engineer" ✓

Experience Detection:
  Regex: (\d+)\+?\s+years?\s+of\s+(?:professional\s+)?experience
  Example: "5 years of experience" ✓

Skills Detection:
  Keywords: Skills:, Technical Skills:, Proficiencies:
  Formats: Comma-separated or newline-separated
  Example: "Python, JavaScript, Java, Go" ✓

Education Detection:
  Keywords: B.A., M.S., Ph.D., Bachelor, Master, Degree, Diploma
  Example: "B.S. in Computer Science" ✓
