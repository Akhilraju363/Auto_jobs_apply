AUTO-FILL LOGIC FLOW
================================================================================

Preference Fields:
  1. User enters: Salary, Notice Period, Visa Status
  2. Saved to chrome.storage.local
  3. Content script loads on page
  4. scanAndFillPreferences() runs
  5. Detects matching fields (salary, notice, visa)
  6. Directly fills with stored preference values
  7. Dispatches input/change events
  8. No API calls, instant population

Behavioral Questions:
  1. Form field detected
  2. Label analyzed for question type
  3. If preference question → use direct fill
  4. If behavioral question → send to Gemini
  5. Gemini processes with humanized prompt
  6. Response filled into field
  7. Natural, grounded answer delivered
